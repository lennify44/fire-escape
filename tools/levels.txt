# Rooms for index.html. Build with: python3 tools/build_levels.py, then check with: tools/check.sh
# Each room: a header line "= FLOOR | Name | hint[ | nodash]", 23 map rows of 40 columns,
# then optional "saws: [...]" and "plats: [...]" JSON lines.
# Legend: # wall  - scaffold (jump through)  = crumbling plank  ^ v < > spikes
#         o saw  * dash refill  T spring  S start  C checkpoint  E exit  K gold hard hat
#         { } conveyor belt pushing left/right  F fan (blows up to the next wall)  R B breaker blocks (swap every 1.5 s)
# saws:  {"a":[c,r],"b":[c,r],"t":frames} on a rail, or {"o":[c,r],"rad":tiles,"t":frames,"n":count} orbiting
# plats: {"a":[c,r],"b":[c,r],"t":frames,"w":tiles} jump-through board moving between two tile positions
# via:   [[c,r], ...] waypoints in route order; only tools/solve.js reads them, to search the intended route first
